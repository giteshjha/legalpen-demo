# LegalPen — the diary that keeps itself

A demo of a practice-organisation tool for a solo litigation lawyer in India. Write each hearing
down **once** — what the court did, the next date, anything directed — and every other page builds
itself: tomorrow's board, the dates that cannot slip, the story of each case, the papers in order.

**Try it:** https://giteshjha.github.io/legalpen-demo/

**The desk** (on a laptop): time on the left, the day in the middle, and whichever file you pick
up on the right. On a phone it becomes a single column with the same register.

**Everything is capture.** Add papers (a Registry-objection paper births a refile clock; certified-copy
papers feed the appeal window directly), edit covers (a consultation gets its case number the day
it is filed), record hearings past or future, record results with the forum-correct appeal window,
move a listing the court re-dated without faking an outcome, keep fees the way the paper diary's
back pages do, tick the cause-list check, and let the munshi hold the pen.

Worth trying, in order: **Close the day** → **tomorrow's board built itself** → tomorrow's
**cause-list mismatch** → open **Bhasin v. Chandna** (the appeal clock reads the certified-copy
papers) → search **wagle** → new matter, type **Narain**.

Everything is invented — a fictional Delhi practice on a fictional Wednesday, 19 August 2026.
Nothing you type leaves the page; refresh and the demo is pristine again.

Older versions are preserved at git tags `v1-original-demo` and `v2-single-column`.
